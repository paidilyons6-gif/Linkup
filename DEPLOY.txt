# Deploy to Netlify (drag & drop)

1. Download **LinkUp-netlify.zip**
2. Go to https://app.netlify.com/drop
3. Drag the zip onto the page (or unzip and drag the folder that contains `index.html`)
4. Netlify gives you a live URL like `https://something.netlify.app`

That’s enough to show Becca the marketing site + demo quiz.
