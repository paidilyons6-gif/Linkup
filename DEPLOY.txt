# Deploy to Netlify (drag & drop)

1. Download LinkUp-netlify.zip from this repo
2. Go to https://app.netlify.com/drop
3. Drag the zip onto the page
4. Live site: **https://linkupping.netlify.app**
5. Share that URL with Becca

## After Netlify is live

In Supabase → Authentication → URL Configuration:
- Site URL = your Netlify URL
- Redirect URLs include `https://YOUR-SITE.netlify.app/**`

And set Edge Function secret SITE_URL to the same Netlify URL.

## Security

Rotate the Supabase access token you pasted in chat (Dashboard → Account → Access Tokens).
