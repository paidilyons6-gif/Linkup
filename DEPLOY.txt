## Backend

Supabase project `linkup` (`ldaajbuumgjujfwmlcwm`) is production-hardened:

- RLS + least-privilege grants (anon cannot read profiles/subscriptions)
- Publish blocked without an active paid plan
- Quiz gated to Guide/Scale; email capture to Scale
- Public taps/email signup via `record_tap` / `join_list` RPCs only
- Stripe Checkout + webhook + billing portal deployed
- Broadcasts require Scale + Resend secrets (not configured yet → safe 503)
